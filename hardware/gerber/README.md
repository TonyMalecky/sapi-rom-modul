# Výrobní podklady DPS

Gerber a vrtací soubor pro výrobu desky plošných spojů SAPI 4.

- `COPPER_TOP.GER` – horní měděná vrstva.
- `COPPER_BOTTOM.GER` – spodní měděná vrstva.
- `SOLDERMASK_TOP.GER` – horní nepájivá maska.
- `SOLDERMASK_BOTTOM.GER` – spodní nepájivá maska.
- `SILK_TOP.GER` – horní potisk.
- `PROFILE.GER` – obrys desky.
- `DRILLS.xln` – vrtací data ve formátu Excellon.

Gerber soubory uvádějí jednotky v milimetrech; vrtací soubor také používá metrické jednotky. Před objednáním výroby zkontrolujte všechny vrstvy, obrys a vrtání v CAM prohlížeči výrobce DPS.
